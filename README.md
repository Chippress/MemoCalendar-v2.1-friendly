# MemoCalendar（纪念日日历）

用于记录周年纪念日、生日、纪念事件等重要日期的桌面应用。
更多信息见 更新日志.txt。

## 功能概览
- 在日历上点击日期即可编辑当天内容
- 支持创建和切换不同的纪念日数据文件
- 以 `.mmcld` 文件保存日历数据，方便备份和迁移
- 适合记录生日、纪念日、节庆、提醒事项等

## 数据文件说明
`.mmcld` 是本程序的数据文件，保存纪念日信息。  
你可以：
- 新建一个自己的数据文件
- 复制示例文件后修改内容
- 在软件中切换不同的日历文件

## 项目结构
- `app.jar`：可执行程序
- `default_info.mmcld`：示例数据
- `chprs/src/`：Java 源代码
- `更新日志.txt`：版本更新记录

## 备注
该项目是基于 Java Swing 的桌面应用，适合本地使用。  
如果你想自定义纪念日内容，最关键的就是维护好 `.mmcld` 文件。
